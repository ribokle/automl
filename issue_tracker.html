#001 P0 Open advanced_eda
advanced_eda crashes with OOM when run on full Dominick's panel (99M rows)
Symptom: The advanced_eda agent fails with cannot allocate memory for array and exits without producing any artifacts. All downstream agents (feature_engineering → insights) are left in pending state, blocking the full pipeline run.

Root cause: _read_raw_panel() in core/agents/advanced_eda.py:71 executes SELECT * FROM main.panel and materialises the entire 99M-row result into a single pd.DataFrame in memory (~12–15 GB at ~150 bytes/row). The machine cannot allocate this. The call succeeds on the synthetic dataset (~20k rows) and on single-category Dominick's runs, but fails when all 29 categories are loaded (98,884,285 rows across 17,928 SKUs / 93 stores / 398 weeks).

Confirmed timeline (run 448e47cac13d):
  • 11:56:10 — agent started
  • 11:56:16 — ppg_week_aggregate succeeded (456,251 rows — fine)
  • 12:00:11 — OOM crash, ~4 min after start (during _read_raw_panel)
Error event (events.jsonl):
{"type": "agent_failed", "agent": "advanced_eda", "error": "cannot allocate memory for array"}

Likely allocation site:
  core/agents/advanced_eda.py:139  raw = await asyncio.to_thread(_read_raw_panel, duckdb_path)
  core/agents/advanced_eda.py:75   df = con.execute("SELECT ... FROM main.panel").df()
  → pandas materialises 99M rows × 20 columns into RAM
Consumers of raw that drive the full-table load: store_variability(raw), pareto_abc(raw, panel), holiday_lift_table(raw), cardinality_report(raw, [...]), _ppg_category_lookup(raw).

Suggested fix directions:
  1. Replace _read_raw_panel with per-function DuckDB queries — push aggregations into SQL so only small result sets cross the DuckDB→pandas boundary.
  2. Or stream a sampled / store-aggregated slice: SELECT … FROM main.panel USING SAMPLE 10% (fast, approximate).
  3. Or cap the raw load to the top-K PPGs by revenue (already computed in top_ppgs) so the WHERE clause prunes to a manageable slice before materialisation.
Affected files: core/agents/advanced_eda.py, core/features/advanced_eda.py (functions that accept a full raw DataFrame).
